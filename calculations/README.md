# Design calculations

`Lightsabre_Design_Calculations.sm` is the complete SMath Studio worksheet behind
the design calculations summarised in Appendix D of the report (Calculations) and
Section 4.6 (Detailed System Design).

It covers:

- LED data transmission and controller processing capacity
- Motion sensor data transfer
- Power demand, brightness limit and buck converter duty cycle
- Battery pack sizing, operating time and charging
- Wire sizing and connector/terminal ratings
- Hilt and blade loads (grip reactions, shear force, bending moment, stress, deflection)
- Blade mount adhesive bonds
- Thermal calculations (LED heat, converter heat, hilt ventilation)

Open it with SMath Studio (free): https://smath.com
